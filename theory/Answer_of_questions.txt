۱. تفاوت Git و GitHub چیست؟
Git یک ابزار برای مدیریت و کنترل نسخه‌های کد روی سیستم شخصی است.
GitHub یک پلتفرم آنلاین است که پروژه‌های Git روی آن قرار می‌گیرند و امکان همکاری با دیگران را فراهم می‌کند.
به‌طور خلاصه، Git ابزار است و GitHub محل نگهداری آنلاین پروژه‌هاست.


---

۲. Merge و Rebase چه تفاوتی دارند؟
Merge دو شاخه را با هم ادغام می‌کند و تاریخچه تغییرات را به همان شکل نگه می‌دارد.
Rebase تغییرات یک شاخه را روی شاخه دیگر قرار می‌دهد و باعث مرتب‌تر شدن تاریخچه می‌شود.
معمولاً برای کارهای ساده از Merge استفاده می‌شود.


---

۳. conflict چگونه به وجود می‌آید و چگونه حل می‌شود؟
Conflict زمانی ایجاد می‌شود که دو تغییر متفاوت روی یک بخش از یک فایل انجام شده باشد.
برای حل آن، فایل مربوطه بررسی می‌شود، تغییر صحیح انتخاب یا ترکیب می‌گردد و سپس دوباره commit انجام می‌شود.
